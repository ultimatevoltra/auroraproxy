Documentation

API reference

Integrate AuroraProxy into any app.

Endpoints

MethodEndpointDescription
GET / POST/api/proxyProxy a request through a rotating exit
GET/api/proxy/ipLive egress IP of the current rotating exit
GET/api/healthHealth check { status:"ok", version:"1.0.1" }
GET/api/versionVersion + engine metadata

Request parameters

FieldTypeReqDescription
urlstringyesTarget URL to fetch
countrystringnoExit region: us/eu/sg/jp/in/br
modestringnoauto (default) / text / json / base64 / stream
methodstringnoHTTP method (default GET)
timeoutnumbernoTimeout in ms (default 30000)
gatewaystringnoSet 0 to bypass rotating exit (direct fetch)

Examples

cURL — fetch through a rotating exit
curl "https://YOUR_HOST/api/proxy?url=https://api.ipify.org?format=json&mode=json"
Live egress IP
curl "https://YOUR_HOST/api/proxy/ip"
# {"ok":true,"proxy_country":"auto","ip":"51.38.132.86",...}
Python
import requests
r = requests.get("https://YOUR_HOST/api/proxy",
    params={"url":"https://api.ipify.org?format=json","mode":"json"})
print(r.json())
Stream video (seek)
curl -H "Range: bytes=0-1023" \
  "https://YOUR_HOST/api/proxy?url=https://example.com/video.mp4&mode=stream"
